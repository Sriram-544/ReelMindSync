Instaloader fetches all your saved Reels along with JSON metadata — captions, timestamps, hashtags, and more.

Whisper transcribes audio speech, EasyOCR reads on-screen text, and JSON captions are combined into a single rich content blob per Reel.

Open Source Stack

Downloads saved Reels and their full metadata JSON. No Instagram API approval required.

World-class speech recognition running fully offline. Choose from tiny (39MB) to large (1.5GB) models.

base ✓ small medium

On-Screen Text

EasyOCR

Reads burned-in captions, subtitles, and overlaid text from sampled video frames. Supports 80+ languages.

Vector DB

ChromaDB

Persists embeddings to disk with cosine-similarity HNSW indexing. Searches millions of vectors in milliseconds.

Quick Start

Get running in minutes

Four commands and you're live. No accounts, no credit cards, no cloud.

1

Install Dependencies

requirements.txt 
pip install instaloader openai-whisper easyocr \
  chromadb sentence-transformers \
  langchain langchain-community \
  langchain-ollama streamlit tqdm
2

Download Your Saved Reels

bash 
instaloader --login YOUR_USERNAME :saved
3

Install Ollama + Pull a Model

bash 
# Mac / Linux
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.2
4

Process, Index & Launch

bash 
python extract/consolidate.py
python index/indexer.py
streamlit run chat/app.py

FAQ

Common Questions

ReelMind uses Instaloader to download your own saved content for personal, offline use. Always review Instagram's current Terms of Service. ReelMind itself is purely a local tool — it does not scrape public content or automate engagement.
Whisper's "base" model achieves word error rates under 5% for clear English speech. Use the "small" or "medium" model for better accuracy on accented speech or multiple languages.
Expect roughly 5–10 minutes per 100 Reels on a modern CPU (faster with a GPU). Processing is a one-time cost — subsequent chats are instant once indexed.
Yes! Whisper and EasyOCR both support CUDA (NVIDIA) and MPS (Apple Silicon). Install the appropriate PyTorch version and models will automatically use your GPU.
Whisper supports 99 languages natively. EasyOCR supports 80+ languages. Configure both with the languages relevant to your Reel collection.
